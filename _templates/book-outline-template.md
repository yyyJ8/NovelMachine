# 大纲模板 — {书名}

> 使用方式：人类先填初稿，模型逐段给建议 → 人类修改 → 循环到满意 → 人类拍板。
> 模型只建议不决定。所有最终决策由人类做出。

{这是一个什么样的世界？最独特的规则是什么？和读者熟悉的仙侠有什么不同？}

## AI 交互流程

大纲的交互是**逐段推进**的——填完一段，AI 给建议，你修改或确认，再进入下一段。

### 第一轮：书名 + 一句话梗概

```
AI：「先定书名和简介——这两样是读者在信息流里看到的第一眼。
  我会按『极端词 + 身份反差 + 热词』出 3-5 个候选，每个标清楚卖点。
  你选一个或组合修改，拍板后我们配套写简介，然后进梗概。」

书名候选 → 你选/改 → 拍板 → 简介确认

你写梗概初稿 →

AI：
  - "这句梗概里，最有记忆点的元素是 X。有没有办法让 Y 更具体？"
  - "读者看完这句，第一反应会是什么？如果反应不是你想要的方向，可能是 Z 元素需要调整。"
  - "书名承诺的卖点是 X，梗概也要往 X 上收——两者是同一个广告。"
```

### 第二轮：核心设定

```
AI：「接下来是世界设定。一句话——这是一个什么样的世界？最独特的一条规则是什么？」

你写世界观 → AI 给建议 → 你修改 →
你写金手指 → AI 给建议 → 你修改 →
你写修炼体系 → AI 给建议 → 你修改
```

### 第三轮：主角弧光 + 分卷规划

```
AI：「现在来填主角——他从哪走到哪。先分别写初始和最终状态，再简单列一下每卷大概要干什么。」

你填弧光表 + 分卷表 → AI 检查：
  - "弧光的跨度合理吗？"
  - "分卷的节奏有没有问题？第一卷的落点够不够钩住读者？"
```

### 第四轮：配角 + 反大纲

```
AI：「最后两个——重要配角，以及'这本书不要什么'。」

你填配角表 + 反大纲 → AI 检查：
  - "这些配角各有一条独立的故事线吗？还是都是主角的工具人？"
  - "反大纲里有没有东西和你前面的设定冲突？"
```

### 全稿通读

```
AI：「书名和六段都填完了。我通读一遍，给你一份整体反馈。」

AI 输出：
  - 最大的亮点（这本书最独特的地方在哪）
  - 最大的风险（可能崩在哪）
  - 需要更多思考的点（哪些地方现在还不够清晰）
  - 不太确定对不对的点（没有建议，只是标注出来让你自己考虑）

你修改 → 拍板 → 大纲完成。
```
