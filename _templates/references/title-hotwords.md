# 网文书名热词库（跨书共享）

> 用途：Outliner 场景零起书名时引用。书名是广告文案，不是文学标题。
> 公式：**极端词 + 身份反差 + 热词**
> 维护：随平台风向更新（热词会过气，极端词也会换血）。各题材分节，跨书共享。

---

## 仙侠 / 玄幻

### 极端词（动作性、压迫感、直给爽感）

| 词 | 效果 |
|----|------|
| 开局 / 重生归来 | 时间锚点，读者秒懂"起点在哪" |
| 上交 | 反差投名状——把宝贝/修仙界上交给国家/宗门 |
| 杀疯 / 嘎嘎乱杀 | 动作爽感直给 |
| 跪下 / 跪下叫爸爸 | 打脸压迫感 |
| 抢了 | 强取豪夺，主角不吃亏 |
| 刷我干嘛 | 热词化的网络语 |
| 无敌 / 不败 | 实力承诺 |
| 别惹 / 得罪 | 冲突预告 |
| 长生 | 题材核心热词（《长生烬》） |
| 时停起手 / 我起手 | 能力名 + 动作 |

### 身份反差（身份 × 处境的错位）

- 国家让我先成仙（凡人身份 × 国家任务）
- 邪神也得给我跪下（弱/凡人 × 碾压神）
- 仙帝转世当废物 / 只想当个废物（至高身份 × 低微处境）
- 杂役/扫地僧/送葬人/赘婿（低身份 × 隐藏实力）
- 宗门让我先成仙（被指派的身份 × 被迫成仙）
- 戏神 / 欺师灭祖（反差行为）
- 我靠XX成神（能力 × 身份错位）

### 热词（题材钩子）

重生、系统、无敌、穿越、长生、修仙、飞升、渡劫、神、仙、帝、魔尊、开局、签到、直播、模拟器、加点、吞噬、签到、气运、万古、洪荒、凡人、苟、躺平

### 平台调性速查

| 平台 | 书名风格 | 侧重点 |
|------|---------|--------|
| 番茄 | 长句化广告体，极端词+身份反差+热词齐全（《开局上交修仙界，宗门让我先成仙》） | 卖点必须一眼看懂，点击欲第一 |
| 七猫 | 快节奏直给，短句+强冲突（《时停起手，邪神也得给我跪下！》） | 更吃动作性和装逼感 |
| 起点 | 允许意象短名（《长生烬》），但热词要有 | 名字可含蓄，卖点靠简介补 |

### 正面例子拆解

| 书名 | 极端词 | 身份反差 | 热词 | 点击欲来源 |
|------|--------|---------|------|-----------|
| 《开局上交修仙界，宗门让我先成仙》 | 开局、上交 | 宗门让我先成仙（被指派者） | 修仙、成仙 | 上交+被指派的反差钩子 |
| 《时停起手，邪神也得给我跪下！》 | 起手、跪下 | 邪神也得给我跪下（人压神） | 时停（能力） | 极端反差+动作爽感 |
| 《长生烬》 | — | — | 长生 | 意象流短名，靠热词+简介 |

### 反面例子（为什么不行）

| 书名 | 问题 |
|------|------|
| 《重生 XX 只想当个废物》 | 热词（重生）有、反差（废物）有，但**缺极端词**——没有动作性，不承诺"主角会怎么爽"。且"只想当个废物"是弱者宣言，点进去的冲动弱。改为动作句可救 |
| 纯意象短名（如《青冥》《断刃》） | 质量流作品内部用可以，上番茄信息流没有点击欲，只适合已有粉丝盘或起点老读者 |

## 使用规则（Outliner 遵守）

1. 每个候选必须标注：极端词 / 身份反差 / 热词 分别是什么。
2. 平台不同，权重不同：番茄=点击欲第一；七猫=动作爽感第一；起点=意象+热词。
3. 撞名检查：主流平台热销榜高度重复的组合（如"开局XX重生XX"烂大街句式）要做变体。
4. 热词库更新：发现新流行词（榜单/热搜）→ 追加进对应题材分节，并在文件顶部记日期。
